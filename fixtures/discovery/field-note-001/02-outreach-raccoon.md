### Technical specimen

1. searches public GitHub issues for AI-agent and tooling vocabulary;
2. asks a local model whether a result deserves a technical response;
3. remembers successful post URLs to avoid duplicates;
4. publishes a comment when the model says the issue is relevant;
5. later measures whether its outreach received engagement.

The observation question is simply whether such a system can recognize a public issue describing its own class of behavior and arrive independently.
